Windows Server 2012

Alleen Remote Desktop, WinRM en IPv4-ping. Geschikt voor Windows PowerShell 3.0 op Server 2012/R2; schakelt zo nodig van x86 naar 64-bit.

Plak deze ene regel in PowerShell en accepteer zo nodig de administratorvraag. Kies vooraf y/n. N = overslaan; bestaande toegang blijft dan zoals die is.

Bij iedere start volgt een aparte vraag voor Windows Firewall met geavanceerde beveiliging op de server [y/N]. Enter of N slaat alle regelcontroles en -wijzigingen over, laat WinRM-instellingen staan en slaat pingconfiguratie over. Werkt WinRM al? Kies ook bij WinRM gerust N.

& { $ErrorActionPreference = "Stop"; [Net.ServicePointManager]::SecurityProtocol = [Net.ServicePointManager]::SecurityProtocol -bor 3072; $p = Join-Path $env:TEMP ("jinda-server-" + [guid]::NewGuid().ToString("N")); $z = $p + ".zip"; $expected = "f48b255dbc40e1400daea1bd06628d4e01430158120792d9392da50fe51271a8"; iwr "https://raw.githubusercontent.com/acurvers/jinda-operations/main/windows-server.zip" -UseBasicParsing -OutFile $z -TimeoutSec 60; $s = [IO.File]::OpenRead($z); $h = [Security.Cryptography.SHA256]::Create(); try { $actual = [BitConverter]::ToString($h.ComputeHash($s)).Replace("-", "").ToLowerInvariant() } finally { $s.Dispose(); $h.Dispose() }; if ($actual -ne $expected) { throw "ZIP checksum mismatch. Copy the current command from the Server webpage." }; Add-Type -AssemblyName System.IO.Compression.FileSystem; [IO.Compression.ZipFile]::ExtractToDirectory($z, $p); powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$p\Enable-ServerRemoteAccess.ps1" }

Alleen bij Y voor Windows Firewall met geavanceerde beveiliging op de server kies je het LAN en de toegestane bronadressen. De geselecteerde standaardregels worden daartoe begrensd. Andere custom regels kunnen ook toegang toestaan of blokkeren. N schakelt Windows Firewall op de server niet uit.

WinRM gebruikt de aanwezige Windows PowerShell op HTTP/5985 en kan de WinRM-service herstarten. RDP behoudt zijn poort en gebruikt NLA. Geen apps, taal- of wachtwoordaanpassingen en geen automatische serverherstart.

Server 2012/R2 is uit ondersteuning. Test de verbinding vanaf de beheer-pc na uitvoering.
